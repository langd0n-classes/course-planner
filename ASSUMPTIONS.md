# Assumptions

Decisions made where the requirements were underspecified. Each can be revisited.

The assumptions are in `docs/assumptions/`, one file for each change.

- A file for a change that has an issue is named `<issue number>-<slug>.md`, for example `085-meeting-placement.md`.
- The files named `legacy-NN-<slug>.md` hold the sections that were in this file before 2026-11-16, in their original order.

To record a new assumption, add a new file in `docs/assumptions/`. Do not add text to this file.
